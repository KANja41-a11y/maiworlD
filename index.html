04 · TENTANG

Tentang MAIWORLD

MAIWORLD adalah situs statis — dibangun murni dengan HTML, CSS, dan JavaScript. Semua karakter, dunia, teman, dan pilihan kustomisasi disimpan sebagai file JSON supaya gampang dikembangkan tanpa menyentuh kode inti.

Karakter chibi di sini digambar langsung lewat kode dari data grid pixel (bukan aset gambar orang lain), jadi bebas dipakai dan diubah-ubah. Karena situs statis tanpa server, fitur "teman online" berjalan lewat data yang sudah disiapkan plus link undangan yang bisa kamu bagikan — bukan koneksi real-time sungguhan antar banyak pengguna sekaligus. Musik latarnya pun dibuat langsung lewat kode (Web Audio API), bukan file lagu, supaya selalu ringan dan bebas hak cipta.

  • Kustomisasi lengkap: kulit, rambut (5 gaya × 6 warna), dress atau atasan+celana terpisah, 7 aksesori
  • Nama karakter bisa diganti kapan saja
  • 3 dunia yang bisa dijelajahi: Taman, Sekolah, Alun-Alun
  • Barang-barang interaktif di tiap dunia dengan obrolan singkat
  • Teman NPC dengan mini-dialog (pilih respons) + High Five
  • Link undangan — karaktermu bisa "hadir" di dunia temanmu
  • Musik latar santai yang dibuat langsung lewat kode

Siapa pun yang membuka link situs ini bisa langsung membuat karakternya sendiri dan main — situsnya publik begitu di-deploy ke GitHub Pages.
